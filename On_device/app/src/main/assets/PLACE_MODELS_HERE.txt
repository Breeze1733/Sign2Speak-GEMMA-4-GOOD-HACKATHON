Place the following files in this directory before building:

1. classifier.tflite      — Generated by: python convert_to_tflite.py
2. model_meta.json        — Copy from: model_winner/model_meta.json
3. hand_landmarker.task   — Download from MediaPipe:
                            https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
4. face_landmarker.task   — Download from MediaPipe:
                            https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task

For the Gemma LLM (optional — app works without it in fallback mode):
- Place gemma4-2b-it-q4.gguf at /sdcard/gemma4-2b-it-q4.gguf on the Android device
